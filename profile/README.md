# QA 校友项目

欢迎访问 QA 校友项目！

## 我们正在维护

### QA瓜田

> 该项目最早于2022年发布，中间经调整后2024年10月重新发布，11月经青岛中学团委王琳、原青岛中学高中部主任王东刚不公正打压被迫关闭。而后于2025年6月重新开放。
>
> 彼时，王琳曾提出问题：如果有人发帖称“王琳是一个不负责任的老师”，我们的审核系统能否拦截？我想，这句话不用被拦截。**王琳就是一个不负责任的老师**。

QA瓜田是我们维护的面向青岛中学和金家岭学校学生的校园论坛，拥有全面的功能和优秀的隐私保护，目前版本为 V4（已开源）。

你可以访问 https://qaguatian.com/ 使用本项目。

V1 - V3 版本现已无法访问，但你可以在[此链接](https://v3.qaguatian.com/)中查看历史数据。

同时我们还展示微信账号 @墙墙 的朋友圈数据：https://qq.qaguatian.com/
